# Aplikasi Absensi Siswa QR

Prototipe daftar hadir dan pulang siswa SMP Negeri 2 Kebonagung dengan scan QR Kartu Siswa.

- 4 mode scan: Datang, Sholat Dhuhur, Pulang (mulai 13.30), Scan Berhalangan
- Rekap Harian, Mingguan, dan Bulanan + unduh CSV
- Halaman Guru ber-PIN (contoh: 1234)
- Halaman Orang Tua untuk memonitor kehadiran dan pulang anak
- Halaman Kartu & QR: unduh kartu per siswa (PNG) dan unduh semua kartu

Data contoh: 12 siswa fiktif (VII A, VIII B, IX C; NIS 2401–2412). Data prototipe hanya tersimpan selama halaman dibuka (in-memory).

Buka: https://masgurubudi.github.io/absensi-qr/
